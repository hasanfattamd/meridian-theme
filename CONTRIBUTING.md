# Contributing to Meridian

First off, thank you for considering contributing to Meridian!

## Development Process

1. Fork the repository
2. Create your feature branch (`git checkout -b feature/amazing-feature`)
3. Commit your changes (`git commit -m 'Add some amazing feature'`)
4. Push to the branch (`git push origin feature/amazing-feature`)
5. Open a Pull Request

## Code Style

This project uses Prettier and ESLint. Please ensure you format your code and run the linter before submitting a PR.
- `pnpm run format`
- `pnpm run lint`

## Architecture Principles

- Keep it simple: Avoid creating unnecessary abstractions (e.g., core/, foundation/, base/).
- Prefer readability over cleverness.
