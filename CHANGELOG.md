# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-09-20
### Added
- Initial release of Meridian, a dark theme generated by the Meridian design system.
- 13 variants: Dark, Ultimate, Noir, Fire, Luxe, Midnight Glow, Elegance, Deep Sea, Slate, Deep Wine, Forest, Umbra and Polar Night.
- Full workbench theming and shared TextMate syntax mappings across all variants.
